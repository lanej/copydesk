# Initial protocol baseline

`editorinterop-v1.binpb` is the compiled v1.0 contract frozen for the first implementation. It is the explicit initial compatibility baseline while the PR base has no schema. After this API reaches the integration branch, CI compares against the actual PR base or prior push instead. Do not regenerate this snapshot to make a breaking change pass.

This baseline establishes the starting schema; it does not claim compatibility with a previously released API. Runtime fixtures and host/client acceptance establish behavior separately.
